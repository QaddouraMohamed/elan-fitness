# Élan Fitness 💪

A simple gym website project built to practice and improve my HTML and CSS skills.

🔗 **Live Demo:** [Élan Fitness](https://qaddouramohamed.github.io/elan-fitness/index.html)

## 📖 About

Élan Fitness is a fictional fitness center website based in Casablanca, Morocco. It presents the gym, its programs, and contact information through a simple, organized multi-page layout.

This project was created as a learning exercise to explore the fundamentals of web development and improve my ability to structure and style web pages.

## 🎯 Project Tasks

- Separate the website into individual pages.
- Create a dedicated contact page.
- Style the pages using CSS.
- Organize the project files into a clear structure.

## 📚 What I Learned

While working on this project, I practiced:

- HTML boilerplate and document structure
- HTML tags and attributes
- CSS selectors and combining selectors
- CSS cascading and specificity
- CSS floats
- CSS Flexbox
- Creating and styling multi-page websites
- Maintaining a clean project structure

## 🛠️ Technologies

- **HTML5** — Page structure and content
- **CSS3** — Styling and layout

## 🚀 Getting Started

To view the project locally:

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## 🎓 Purpose

The main goal of this project was to gain hands-on experience with HTML and CSS, understand how multiple pages work together, and build a foundation for future web development projects.
